# 🌿 Oogrow — Organic & Natural Store (Pakistan)

> Premium E-Commerce Platform for Organic Dry Fruits, Cold Pressed Oils, Pure Himalayan Shilajit, and Herbal Wellness Products in Pakistan.

---

## ✨ Features & Architecture

Oogrow is built as a blazing fast, single-file modern web application (`index.html`) optimized for Pakistani e-commerce workflows, WhatsApp checkout, and seamless mobile-first browsing.

### 🛍️ Customer Experience
- **Premium Design System:** Deep emerald green (`#0B3B24`), organic gold (`#D4AF37`), clean typography, and 100% uniform product cards across all screen sizes.
- **WhatsApp Direct Checkout:** Seamless cart drawer with automatic COD and WhatsApp order dispatch to customer service (+92 340 7281857).
- **Public Live Order Tracking (`#/track`):**
  - Instant lookup by Phone Number, Order ID (`OG-1001`), or WhatsApp Checkout Reference (`OG-WA-XXXX`).
  - 4-stage visual progress stepper (*Order Placed* → *Confirmed* → *Dispatched* → *Delivered*).
  - Courier tracking links (TCS, Leopards, Trax, PostEx, Call Courier, M&P).
  - Privacy-protected phone masking (`0340 •••• 857`).
- **Live Search & Autocomplete:** Real-time dropdown search with instant thumbnail previews, price tags, and category badges.
- **Shop Sorting:** Sort products by Price (Low to High / High to Low), Customer Rating, and Bestseller status.
- **Mobile Sticky "Add to Cart" Bar:** Fixed bottom bar on product detail pages with live weight/variant price calculation.
- **Shilajit Lab Report Viewer:** Interactive zoomable modal showcasing 100% Purity Certification, Fulvic Acid metrics (72.4%), heavy metal clearance, and direct WhatsApp COA PDF request.
- **Rich Contact Form:** AJAX contact submission via FormSubmit directly delivered to store management (`zulqurnainhaider000@gmail.com`).
- **Full SEO & Social Sharing:** Dynamic Open Graph metadata, Twitter Cards, and Google Schema.org structured data (`Store`, `Organization`, `WebSite`).

---

### 🛡️ Built-in Admin Dashboard (`#/admin`)
- **Store Setup Checklist:** Launch readiness tracker with progress bar, automated password audit, export reminder, and direct section shortcuts.
- **Order Management:** Filter by status, search by customer/phone/ref, and view detailed customer orders.
- **One-Click Printable Invoice / Parcel Slip:** Thermal and A4 compatible COD delivery slip with barcode, itemized order breakdown, customer contact details, and printable CSS.
- **Customer Status WhatsApp Notifications:** 1-click wa.me templates with dynamic placeholders for Confirmed, Dispatched (with courier and tracking link), and Delivered notifications.
- **Product & Inventory Management:** Add, edit, or adjust pricing, stock, weights, and descriptions.
- **Media & Reviews Management:** Control customer testimonials, rating distribution, and media assets.
- **Local Storage Backup & Restore:** 1-click JSON export and import for 100% data safety (`oogrow_data_v1`).

## 🚀 Quick Start / Local Development

### Option 1: Direct Browser
Open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Safari, Firefox).

### Option 2: Local HTTP Server (Node.js)
```bash
node server.js
# Opens at http://localhost:3000/
```

### Option 3: Python Simple Server
```bash
python -m http.server 8000
# Opens at http://localhost:8000/
```

## 🌐 Deploy to GitHub Pages (1-Click Hosting)

1. Push this repository to GitHub.
2. In your repository on GitHub, go to **Settings** → **Pages**.
3. Under **Build and deployment** → **Source**, select `Deploy from a branch`.
4. Choose Branch: `main` and Folder: `/ (root)`.
5. Click **Save**. Your website will be live in 1 minute at:
   `https://<your-username>.github.io/<repo-name>/`
